# Security Policy

## Supported Version

Security and privacy corrections are applied to the current default branch. No tagged releases are currently maintained.

## Reporting a Vulnerability or Privacy Exposure

Do not publish credentials, personal identity numbers, private correspondence, or exploitable details in a public issue. Email the maintainer at `jrodvel011@gmail.com` with the repository name, affected path, impact, and a minimal reproduction.

Ordinary non-sensitive bugs and factual data corrections may use the repository issue templates. GitHub private vulnerability reporting is not currently enabled for this repository.
