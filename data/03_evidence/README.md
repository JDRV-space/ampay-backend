# Dated Evidence

This directory preserves audits and historical analyses that explain prior decisions but do not own current public behavior.

- `promise_extraction_audit.md` records the January 2026 removal of potential promise hallucinations.
- `quiz_position_audit.json` is a historical eight-question position audit and does not validate the current 15-statement quiz.
- `ampay_v4_analysis/` contains historical candidate analyses with obsolete schemas and AMPAY counts.

Current public outputs live in `data/02_output/` and are validated by `python3 scripts/validate_current_outputs.py`.
